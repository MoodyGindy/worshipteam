# 🎵 لعبة الأسئلة - Quiz Game

لعبة أسئلة تفاعلية في الوقت الفعلي لـ 200-300 لاعب مع أسئلة بالعربية عن الموسيقى والكتاب المقدس والمعلومات العامة والرياضة.

## 🎯 المميزات

- دعم 200-300 لاعب في وقت واحد
- الانضمام عبر رمز QR
- أسئلة باللغة العربية مع دعم RTL
- 4 خيارات لكل سؤال
- عرض النتائج والنقاط في الوقت الفعلي
- لوحة المتصدرين المباشرة
- عرض الفائزين الثلاثة الأوائل
- فئات متنوعة: موسيقى، الكتاب المقدس، معلومات عامة، رياضة

## 📋 المتطلبات

- MAMP (أو XAMPP/WAMP)
- PHP 7.4 أو أحدث
- MySQL 5.7 أو أحدث
- Composer
- متصفح حديث يدعم WebSocket

## 🚀 التثبيت والإعداد

### الخطوة 1: تثبيت Composer Dependencies

افتح Terminal وانتقل إلى مجلد المشروع:

```bash
cd /Applications/MAMP/htdocs/worshipteam
```

ثبت المكتبات المطلوبة:

```bash
composer install
```

### الخطوة 2: إعداد قاعدة البيانات

1. افتح MAMP وشغل Apache و MySQL
2. افتح phpMyAdmin: https://kdsc.fun/phpMyAdmin
3. قم باستيراد ملفات قاعدة البيانات:

```bash
# من Terminal، قم بتشغيل:
mysql -u root -p < database/schema.sql
mysql -u root -p < database/sample_questions.sql
```

أو يمكنك استخدام phpMyAdmin:
- افتح phpMyAdmin
- اضغط على "Import"
- اختر ملف `database/schema.sql` أولاً
- ثم اختر ملف `database/sample_questions.sql`

### الخطوة 3: تكوين قاعدة البيانات

افتح ملف `config/database.php` وتأكد من الإعدادات:

```php
'host' => 'localhost',
'port' => 3306,
'database' => 'quiz_game',
'username' => 'root',
'password' => 'root', // كلمة المرور الافتراضية لـ MAMP
```

### الخطوة 4: تشغيل خادم WebSocket

افتح Terminal جديد وشغل:

```bash
cd /Applications/MAMP/htdocs/worshipteam
php server.php
```

يجب أن ترى:
```
WebSocket server started on port 8080
```

**ملاحظة مهمة:** يجب أن يظل هذا Terminal مفتوحاً أثناء اللعبة!

### الخطوة 5: الوصول إلى اللعبة

1. **عرض المضيف (الشاشة الكبيرة):**
   افتح في المتصفح:
   ```
   https://kdsc.fun/worshipteam/host.html
   ```

2. **عرض اللاعب (الموبايل):**
   امسح رمز QR الذي يظهر على الشاشة الكبيرة
   أو افتح:
   ```
   https://kdsc.fun/worshipteam/player.html?code=XXXXX
   ```

## 🎮 كيفية اللعب

### للمضيف (الشاشة الكبيرة):

1. افتح `host.html` على الشاشة الكبيرة
2. سيظهر رمز QR ورمز اللعبة
3. انتظر انضمام اللاعبين
4. اضغط "ابدأ اللعبة" عندما يكون الجميع جاهزين
5. ستظهر الأسئلة تلقائياً مع المؤقت
6. بعد كل سؤال، ستظهر الإجابة الصحيحة ولوحة المتصدرين
7. اضغط "السؤال التالي" للانتقال
8. في النهاية، اضغط "عرض الفائزين"

### للاعبين (الموبايل):

1. امسح رمز QR أو أدخل رمز اللعبة يدوياً
2. أدخل اسمك واضغط "انضم"
3. انتظر بدء اللعبة
4. عند ظهور السؤال، اختر الإجابة من الخيارات الأربعة
5. اضغط "إرسال الإجابة"
6. ستظهر نتيجتك ونقاطك
7. انتظر السؤال التالي
8. في النهاية، ستشاهد ترتيبك النهائي والفائزين

## ⚙️ API Endpoints

- `POST /api/create-game` - إنشاء لعبة جديدة
- `GET /api/get-game?code=XXXXX` - الحصول على معلومات اللعبة
- `GET /api/get-questions?limit=20` - الحصول على الأسئلة
- `GET /api/get-leaderboard?code=XXXXX` - الحصول على لوحة المتصدرين
- `GET /api/get-stats?code=XXXXX` - الحصول على إحصائيات اللعبة

## 🔌 WebSocket Events

### من العميل إلى الخادم:
- `join` - الانضمام إلى اللعبة
- `answer` - إرسال إجابة
- `start_game` - بدء اللعبة (المضيف فقط)
- `next_question` - السؤال التالي (المضيف فقط)
- `end_game` - إنهاء اللعبة (المضيف فقط)

### من الخادم إلى العميل:
- `joined` - تأكيد الانضمام
- `player_joined` - إشعار بانضمام لاعب جديد
- `game_started` - بدء اللعبة
- `new_question` - سؤال جديد
- `answer_result` - نتيجة الإجابة
- `game_ended` - نهاية اللعبة والفائزين

## 🎨 التخصيص

### إضافة أسئلة جديدة:

افتح phpMyAdmin وأضف أسئلة في جدول `questions`:

```sql
INSERT INTO questions (question_text, option_a, option_b, option_c, option_d, correct_answer, category, points, time_limit)
VALUES ('سؤالك هنا؟', 'خيار أ', 'خيار ب', 'خيار ج', 'خيار د', 'A', 'music', 100, 30);
```

### تغيير الألوان والتصميم:

عدّل ملفات `host.html` و `player.html` في قسم `<style>`.

### تغيير عدد الأسئلة:

في ملف `js/host.js`، غيّر القيمة في:
```javascript
await fetch(`${API_URL}/get-questions?limit=20`)
```

## 🐛 حل المشاكل

### المشكلة: لا يمكن الاتصال بالخادم WebSocket

**الحل:**
- تأكد من تشغيل `php server.php`
- تحقق من أن المنفذ 8080 غير مستخدم
- تأكد من عدم حظر الجدار الناري للمنفذ

### المشكلة: خطأ في قاعدة البيانات

**الحل:**
- تأكد من تشغيل MySQL في MAMP
- تحقق من صحة بيانات الاتصال في `config/database.php`
- تأكد من استيراد ملفات SQL بشكل صحيح

### المشكلة: رمز QR لا يظهر

**الحل:**
- تأكد من تضمين مكتبة QRCode في `host.html`
- افتح Console في المتصفح وتحقق من الأخطاء
- تأكد من أن JavaScript غير محظور

### المشكلة: اللاعبون لا يستطيعون الانضمام

**الحل:**
- تأكد من أن الأجهزة على نفس الشبكة
- استخدم عنوان IP المحلي بدلاً من localhost للأجهزة الأخرى
- مثال: `http://192.168.1.100:8888/worshipteam/player.html`

## 🌐 الاستخدام على الشبكة المحلية

للسماح للاعبين بالانضمام من أجهزة أخرى:

1. اعرف عنوان IP الخاص بك:
   ```bash
   ipconfig getifaddr en0  # على Mac
   ```

2. عدّل الملفات التالية واستبدل `localhost` بعنوان IP:
   - `js/host.js`
   - `js/player.js`

3. استخدم عنوان IP في المتصفح:
   ```
   http://192.168.1.X:8888/worshipteam/host.html
   ```

## 📊 نظام النقاط

- كل سؤال: 100 نقطة كحد أقصى
- النقاط تعتمد على سرعة الإجابة:
  - إجابة فورية: 100 نقطة
  - إجابة بطيئة: 50 نقطة كحد أدنى
- الإجابات الخاطئة: 0 نقطة

الصيغة:
```
النقاط = 100 × (0.5 + 0.5 × (1 - وقت_الإجابة / 30))
```
